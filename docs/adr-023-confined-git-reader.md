# ADR-023 — Confined, read-only Git reader

14 September 2026. Phase 5 replaces document 06's suggested Git subprocess with `isomorphic-git@1.42.2` and a descriptor-constrained, read-only filesystem adapter. No Git executable or runtime apt layer is needed. Dependencies are exact/integrity-locked; captured production audit reports zero known vulnerabilities. Libraries retain their package licence files.

The parser receives only virtual `/project` paths mapped into one validated project directory. Each physical read uses no-follow descriptors and root identity/containment checks. A separate allowlist permits only necessary `.git` refs, HEAD, index and local loose/packed objects. Repository config is replaced in memory by a fixed read-only interpretation: no include, fsmonitor, external diff, filters, helpers, hooks, remote access or arbitrary shell runs. Missing objects fail; alternates, symlink/gitdir worktrees, submodule traversal, SHA-256/reftable/split-index compatibility are not promised. File APIs still cannot read `.git`.

Status uses `refresh:false`, with filesystem write methods unconditionally rejected. Diffs are only HEAD-to-index or index-to-worktree for a validated relative file path; there is no arbitrary revision or command parameter. Known-sensitive paths are omitted from both Git and file views, not claimed to be a general secret scanner. HEAD/index readback detects changes during inspection; host edits are not an atomic repository snapshot. Symlinks and unsupported metadata fail closed rather than being followed.

Parsing runs in short-lived worker threads with an empty environment, a 128 MiB old-generation heap cap, 10-second wall deadline and maximum two workers. Physical bytes and compressed expansion are bounded to 64 MiB per query; loose objects/delta targets to 8 MiB, packs to 32 MiB, filesystem calls to 20,000 and traversed entries to 12,000. Pack/loose expansion is checked before library decompression. Status responses contain at most 500 changed files and diffs at most 256 KiB; truncation/unsupported states are explicit. Discovery scans up to 200 directories/three levels/32 repositories, skipping dependency/build directories.

Tests exercise real locally created repositories, staged/unstaged/untracked/deleted files, packed objects, unchanged index, binary/oversized diffs, malicious config/hook canaries and forbidden/symlink metadata. These are workspace implementation tests, separate from native-Hermes integration. The file API's existing authentication, no-store and direct-peer request limits will protect Git routes too. No file, Git or Hermes mutation is enabled by Phase 5.

Primary references: https://isomorphic-git.org/docs/en/fs, https://isomorphic-git.org/docs/en/statusMatrix, https://isomorphic-git.org/docs/en/readBlob, https://isomorphic-git.org/docs/en/walk. Local build/typecheck/lint and 181 unit/30 existing wire tests pass for the reader checkpoint; route/UI/image acceptance follows before Phase 5 sign-off.
